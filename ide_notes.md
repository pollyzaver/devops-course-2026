# VS Code vs терминал

Что удобно в VS Code для работы с Git:
1. Наглядная история коммитов и веток на панели Source Control
2. Просмотр diff файла одним кликом, без ручного запуска git diff
3. Быстрый коммит через UI (ввод сообщения + галочка)

Что удобнее в терминале:
- Полный набор команд (rebase -i, cherry-pick, reflog) — в UI это либо неудобно, либо недоступно
